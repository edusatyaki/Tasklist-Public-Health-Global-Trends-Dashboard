Section 01
Problem Statement
🦠 What This Dataset Contains
The Our World in Data compact.csv is the definitive public COVID-19 dataset — 570,606 rows across 262 countries/regions, 61 columns, spanning January 2020 to February 2026. It integrates pandemic metrics (cases, deaths, hospitalisations, ICU, testing, reproduction rate, stringency) with vaccination data and structural country-level indicators (GDP per capita, median age, HDI, hospital beds, diabetes prevalence). This is a rare dataset where you can answer not just what happened — but why it happened differently in different places. It's the benchmark dataset for pandemic data analytics and one of the most-cited public health datasets in the world.
👥 Stakeholders
Primary: Public health policymakers, WHO/CDC analysts, Epidemiologists

Secondary: Healthcare system planners, Vaccine equity researchers, Journalists, Policy researchers
📋 Dataset Structure
262 countries/regions (incl. World aggregates & income group rows)
61 columns: cases, deaths, vax, tests, hospitalisation, policy, demographics
6 years: Jan 2020 – Feb 2026 · 570,606 rows
Huge nulls: many columns missing 30–99% of values

Section 02
Data Cleaning & Engineering
⚠️ Major Data Issues Found
Aggregate rows mixed in: "World", "Europe", "High-income countries", "Asia excl. China" etc. are in the same file as country rows — must be separated, not dropped.
Extreme nulls: human_development_index is 100% null (all 570,606 rows). excess_mortality has 97% nulls. Many columns are missing 40–60% of values — especially for low-income countries.
Zero ≠ NaN: Early pandemic rows show 0.0 for cases/deaths (pre-outbreak), while NaN means data simply wasn't reported. These are different and must be treated differently.
Income group rows: "Upper-middle-income countries", "Lower-middle-income countries" etc. have no continent — these are analytical aggregates, not countries.
Date up to Feb 2026: Data coverage becomes sparse after mid-2024 for many countries as reporting declined.

# Complete cleaning pipeline skeleton
import pandas as pd, numpy as np

df = pd.read_csv('compact.csv')
df['date'] = pd.to_datetime(df['date'])
df = df.drop(columns=['human_development_index']) # 100% null

# Separate real countries from aggregates
real = df[df['continent'].notna()].copy()
world = df[df['country'] == 'World'].copy()
aggregates = df[df['continent'].isna() & (df['country'] != 'World')].copy()

# Latest snapshot per real country
latest = real.sort_values('date').groupby('country').last().reset_index()
latest['cfr'] = latest['total_deaths'] / latest['total_cases'] * 100
latest['age_quintile'] = pd.qcut(latest['median_age'], 5,
labels=['Young','Young-mid','Mid','Mid-old','Old'])

print(f"Real countries: {len(latest)}") # ~239
print(f"World rows: {len(world)}") # ~2,245
latest.to_csv('data/cleaned/covid_latest_countries.csv', index=False)
